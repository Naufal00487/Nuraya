# Nuraya 1.0.0 — APK pengembangan

File yang disediakan:

- `Nuraya-Android.apk`: APK Android hasil build proyek Nuraya, ukuran 25.390.125 byte.
- `Nuraya-source.zip`: source code dan skrip build.
- `SHA256SUMS`: checksum file.
- `BUILD_VALIDATION.md`: hasil pemeriksaan dan batas pengujian.
- `DATA_SOURCES.md`: sumber data dan lisensi.

## Cara memasang

1. Unduh `Nuraya-Android.apk` melalui tombol **Download raw file** pada halaman file GitHub.
2. Jika diunduh di laptop, pindahkan APK ke HP Android melalui kabel USB atau Quick Share.
3. Buka APK di Android 8.0 atau lebih baru, izinkan pemasangan dari aplikasi pembuka file jika diminta, lalu pilih **Instal**.

APK ini ditandatangani dengan sertifikat debug untuk pengembangan. Build, unit test, lint, integritas data, dan tanda tangan telah diperiksa. Pengujian UI dan audio di perangkat belum selesai karena emulator cloud mengalami ANR. Fitur akun dan AI belum aktif; katalog video masih kosong. Lihat laporan validasi untuk rinciannya.

Data Al-Qur'an dan terjemahan memiliki atribusi/lisensi yang dijelaskan dalam `DATA_SOURCES.md` dan source ZIP. Aplikasi ini disiapkan untuk penggunaan gratis dan tanpa iklan.

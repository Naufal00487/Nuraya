# Nuraya iOS — uji iPhone XR

[**Unduh Nuraya iOS (.IPA, 100,2 MB)**](https://github.com/Naufal00487/Nuraya/raw/refs/heads/downloads/nuraya-ios-preview/Nuraya-iOS-XR-unsigned.ipa)

Minimum **iOS 16.0**. Paket ini belum ditandatangani untuk akun Apple pengguna. Pasang melalui **AltStore Classic di Windows**, kemudian pilih **My Apps → +** pada AltStore di iPhone dan pilih file IPA. Akun Apple gratis biasanya perlu refresh sebelum tujuh hari.

Sumber aplikasi yang dibangun: `0c3dab2c0874bd1542ef837a486e59f2b3fcec48`, versi 1.7.1 (build 1), arsitektur ARM64. Seluruh 1.740 aset Android di bundle telah diperiksa dan tidak berubah. Checksum tersedia di [SHA256SUMS.txt](SHA256SUMS.txt); rincian mesin di [VALIDATION.json](VALIDATION.json).

Ini versi uji pribadi dan belum diterbitkan ke App Store. Mikrofon, kompas, performa AI pada A12, audio layar terkunci, dan notifikasi masih memerlukan pengujian pada iPhone fisik. Antarmuka belum diklaim identik piksel demi piksel dengan Android; sebagian terjemahan English belum lengkap. AI membandingkan perkiraan kata, bukan mengesahkan tajwid/makhraj. Suara notifikasi azan memakai cuplikan 28 detik mengikuti batas iOS.

Cabang ini berisi paket unduhan iOS. Sumber dan paket Android tidak dihapus atau ditimpa.

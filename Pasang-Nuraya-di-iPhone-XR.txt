NURAYA iOS — UJI IPHONE XR

File: Nuraya-iOS-XR-unsigned.ipa
Versi: 1.7.1 (iOS build 3)
Minimum: iOS 16.0
Paket ini dipasang melalui iloader (Ubuntu) atau AltStore (Windows); belum merupakan rilis App Store.
Versi Android tetap tersedia di GitHub.

MEMPERBARUI APLIKASI YANG SUDAH TERPASANG
Pilih IPA baru melalui iloader/AltStore dengan Apple ID yang sama, tanpa menghapus Nuraya. Pastikan Pengaturan menampilkan iOS build 3.

PASANG ATAU PERBARUI MELALUI UBUNTU
1. Sambungkan iPhone melalui USB, buka kunci, lalu pilih Trust/Percayai jika diminta.
2. Unduh IPA terbaru, kemudian buka iloader dari https://github.com/nab138/iloader.
3. Masuk dengan Apple ID yang sama, pilih iPhone, lalu Import IPA dan pilih file baru.
4. Jangan hapus Nuraya yang lama. Periksa iOS build 3 di bagian bawah Pengaturan.
5. Putar dari tab Murottal, kembali ke Home selama 15 detik, lalu coba kunci layar satu menit.
Jika iloader terkena error NVIDIA/GBM, jalankan sebagai pengguna biasa:
WEBKIT_DISABLE_DMABUF_RENDERER=1 iloader

PASANG MELALUI WINDOWS
1. Ikuti panduan AltStore Classic untuk menyiapkan AltServer, iTunes, dan iCloud:
   https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows
2. Sambungkan iPhone ke Windows melalui USB dan pilih Trust/Percayai.
3. Dari AltServer, pilih Install AltStore lalu iPhone milikmu. Gunakan Apple ID sendiri pada komputer sendiri.
4. Ikuti petunjuk mempercayai profil pengembang dan mengaktifkan Developer Mode pada iPhone.
5. Simpan IPA Nuraya di aplikasi Files/File pada iPhone.
6. Buka AltStore > My Apps > +, pilih IPA, lalu tunggu sampai selesai. Biarkan AltServer aktif dan terhubung.
7. Buka Nuraya, isi nama profil, dan atur izin lokasi untuk jadwal salat serta kiblat.

Akun Apple gratis biasanya memerlukan penandatanganan ulang sebelum tujuh hari; gunakan iloader lagi atau Refresh All melalui AltStore/AltServer. Tidak perlu mengirim kata sandi atau kode verifikasi Apple kepada pengembang Nuraya.
